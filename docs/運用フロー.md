# 団体受注 Excel運用フロー(Phase 0)

> チーム検討(Webber=ファイル運用 / Hana=業務フロー / Yuri=入力UX)の結論。2026-07-18。
> 構成: **1案件=1ワークブック**(入力→全帳票自動生成)+**共有カレンダーExcel**(全案件横断)。

---

## 1. ファイルの置き場所と鉄則(Webber)

- **SharePoint(Teamsのファイル領域)に全ファイルを置く**。Excelネイティブの同時編集・版履歴(自動)・権限管理が揃う。個人OneDrive/NAS/Google Driveは不採用(消失・ロック合戦・体裁崩れ)。
- **原本を直接開く。ローカルコピー・メール添付での回覧は禁止**(リンクを送る)。

### フォルダ構成・命名
```
/団体受注/
├─ 00_テンプレート/ 団体受注ワークブック_v1.xlsx   ← 読み取り専用・管理者のみ更新
├─ 01_カレンダー/   団体カレンダー_2026.xlsx        ← 年1ファイル
├─ 2026/
│   └─ 2026-070_0815TANA01_田中産業/
│       ├─ 2026-070_田中産業.xlsx   ← 原本(常に1つ)
│       ├─ 送付済/                  ← 客に出したPDF(見積_第2版_0712送付.pdf)
│       └─ 資料/                    ← 名簿・行程表・FAX等
```
- 案件フォルダ名: `予約番号_ブロックコード_団体名`(予約番号先頭=採番順に並ぶ)。**フォルダ名の改名禁止**(リンクが死ぬ)。
- ファイル名に日付やv2を付けない。**版はシートとPDFで管理**(→§4)。

## 2. 案件ライフサイクルと担当(Hana)

| 段階 | 主担当 | やること |
|---|---|---|
| 引合 | 営業 | テンプレをコピーし予約番号で命名。入力フォーム記入。**同時にカレンダーへ1行転記** |
| 仮予約 | 営業 | Status=仮予約、**仮予約期限を必ず入力**(期限なしで見積を出さない)。見積印刷→送付→PDFを送付済へ |
| 確定 | 営業→手配 | Status=確定。**共有シート+工程表を印刷し、営業・手配・フロントで回覧サイン**(引き継ぎの正式ゲート) |
| 2日前 | フロント | 館内案内作成・名前シール・部屋割り連絡(共有シートのチェック欄にサイン) |
| 前日 | フロント+経理 | 料金確認・館内案内印刷・**紙の版数照合**(手元の紙が最新か) |
| 当日 | フロント | 名前シール印刷・添乗員到着確認。当日変更は共有シートに記入 |
| C/O後 | フロント→経理 | 実績(実人数・追加飲食)を確定 → 請求書発行・郵送 → Status=請求済 |
| 入金 | 経理 | 入金確認 → 領収書発行 → Status=入金済。**月次で「入金済以外」を棚卸し** |

**原則: 入力するのは「入力」シートだけ。見積・請求・工程表など自動生成シートの手修正は禁止**(直したければ入力を直す)。手修正が要る=入力フォームの欄が足りないサインなので欄を追加する。

## 3. カレンダー運用(ダブルブッキング防止の要)

- **編集は営業のみ**。他部署は閲覧のみ。
- 転記は「案件一覧」に1行書くだけ。**会場カレンダーは一覧から自動描画**(手で触らない・シート保護済み)。同じ会場・同じ日に2件入ると**赤+「◆重複!」**表示。
- **「カレンダーに載っていない案件は存在しない」**を鉄則に(会場確保=一覧記入をもって成立)。
- 各案件ワークブックの入力シート最下部に**カレンダー転記用の1行**が自動生成される → コピーして一覧に値貼り付け(手打ちさせない)。
- **仮予約期限の監視**: 「今日の要対応」シートを**毎朝朝礼で開く**。期限切れ・3日前・本日C/Iの件数が自動表示。残日数列は黄(3日以内)→赤(超過)。
- 週1回、手配担当が全案件ワークブックと一覧を突合(15分)。

## 4. 版管理

- 客に出す直前に見積書シートをブック内コピー →「見積_第1版_0705」等に改名し**値貼り付けで凍結**。現行シートは常に最新のワーキング。
- 送付したものは必ずPDF化して`送付済/`へ(=どの版をいつ出したかの台帳)。
- 全帳票のフッターに**印刷日時が自動で入る** → 前日チェックで紙の鮮度を照合。
- 細かい巻き戻しはSharePointの版履歴で(自前バックアップを作らない)。

## 5. 変更・キャンセル

- **変更の入口は営業のみ**。営業が原本を直し、共有シート・工程表を再印刷、旧紙は回収(赤線「旧」)。
- 2日前以降の変更はフロント経由可。ただし共有シートに赤ペン+**必ず営業へ即連絡**。
- キャンセル: Status=キャンセル(**行削除禁止**)。カレンダーで自動的に打ち消し線+会場解放。フロントのバインダーから紙を抜くまでがキャンセル処理。

## 6. Excel運用の弱点と回避策(正直に)

| 弱点 | 回避策 |
|---|---|
| 同時編集の上書き事故 | SharePointの共同編集を使う。カレンダー編集は営業に限定 |
| ワークブックとカレンダーの二重入力ズレ | 転記は自動生成行のコピペのみ+週1突合を工程化 |
| 紙の版ズレ | フッター印刷日時+前日チェックに「版数照合」項目 |

これらが辛くなったら Phase 1(Webアプリ化)のタイミング。入力フォームの項目はアプリの入力画面と1:1対応するよう設計済み。

## 7. ワークブックの構成(v1)

| シート | 種別 | 内容 |
|---|---|---|
| 入力 | ✏️入力(緑タブ) | フォーム。会話の順(相手→日程→人数→宿泊→食事→宴会→送迎→条件→明細→社内管理→特記)。記入例は右列グレー。必須欄は空だと赤 |
| 社内共有シート | 自動(青タブ) | A4一枚。フロントチェック欄(2日前/1日前/当日・〆日付自動)+引き継ぎサイン欄つき |
| 見積書/請求書/領収書 | 自動(青タブ) | 請求番号・領収番号は見積番号から自動(Q-→I-/R-)。請求書に振込先自動表示 |
| 工程表 | 半自動(青タブ) | 送迎・到着・設営・食事・出発を入力から自動転記。時刻・担当を書き足す |
| 館内案内アライ/ロッジ・FAX送付状 | 既存 | 従来のまま同居(既存の数式・運用を維持) |
| マスタ | ⚙️設定(灰タブ) | 選択肢リスト・ホテル情報・振込先・カレンダーURL |
| 食事PKG・プルダウンリスト・New Booking Sheet・Group List | 既存(参考) | 従来シートをそのまま保持 |

- 出力シートはシート保護済み(誤編集防止。備考など黄色セルだけ編集可)。解除は「校閲→シート保護の解除」(パスワードなし)。
- 入力シートも保護済みのため、**Tabキーで入力欄だけを順に移動**できる。
