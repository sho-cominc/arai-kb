# 入力項目一覧(たたき台 v1)

> 団体受注アプリの標準入力セット。Dev 作成・チームレビュー済み。**Sho のレビューで確定させる。**
> 項目は運用開始後も追加可能(要件定義 §1-11 の拡張ルールに従う)。これは初期セット約40項目。

**凡例**
- 帳票: **A** 社内共有ページ / **B** 調理・発注書 / **C** 見積・請求・領収 / **D** イベント工程表 / **Cal** カレンダー
- 「複数行」= 明細行として何行でも増やせる入力
- 「条件付き」= 親項目が「あり」のときだけ表示・必須になる(画面が無駄に長くならない)

## 設計メモ
- **導出値は入力しない**: 泊数(#6から)・見積総額(#30から)は自動計算。二重入力は必ずズレる。
- **新規作成時は #1・#6・#7 の3項目だけで下書き保存可**(要件定義 §1-1)。
- 明細系(#18/#23/#28/#30)は可変行=JSONB 側、それ以外は基本カラム+拡張定義、という実装切り分け。
- **成果物別レディネス**: 各帳票の発行に必要な項目が揃っているかを画面上部に表示(例: 調理発注書は #8・#18・#19 が揃って発行可)。
